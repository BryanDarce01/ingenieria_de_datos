# 1. El Driver (arquitectura interna)

El Driver es un [**proceso JVM**](jvm.md) (aunque se use PySpark) que ejecuta el **SparkContext.**

## Responsabilidades técnicas del Driver
## 1.1 Construcción del plan

Convierte API (PySpark / SQL) en:

- Logical Plan

- Optimized Logical Plan

- Physical Plan

Usa:

- Catalyst Optimizer

- Tungsten engine

## 1.2 DAG Scheduler

Una vez existe el Physical Plan:

- Convierte el plan en un **DAG de stages**

- Divide el DAG según **shuffle boundaries**

Reglas:

- Operaciones narrow → mismo stage

- Operaciones wide → nuevo stage

## 1.3 Task Scheduler

- Divide cada stage en tareas

- Una tarea = una partición

- Asigna tareas a los executors disponibles

## 1.4 Coordinación

- Monitorea ejecución

- Maneja retries

- Maneja fallos de executors

- Agrega métricas
