# Raw Logs and Fact Data 

**No son lo mismo**, aunque ambos pueden aparecer en un pipeline de ingeniería de datos.

# 1. RAW LOGS

## Qué son

- Son los datos crudos, tal cual vienen de la fuente:

- Sin limpiar

- Sin validar

- Sin transformar

- Sin modelar

- Sin tipar correctamente

- Con ruido, errores, duplicados, formatos inconsistentes

## Ejemplos

- Logs JSON de un API

- Logs de clicks de un sitio web

- Archivos CSV sin procesar

- Mensajes Kafka, eventos de IoT, payloads completos

- Audit logs, request logs, server logs

## Objetivo

Capturar la verdad original para:

- Auditoría

- Reprocesamiento

- Trazabilidad (data [lineage](../3.%20Apache%20Spark/2.%20elementos_clave/8.%20lineage.md))

- Replay de datos si un pipeline falla

## Propiedad clave

- No están listos para análisis.

# 2. FACT DATA (FACT TABLES)

## Qué son

Son tablas **modeladas**, **limpias**, **transformadas**, optimizadas para **análisis**, típicamente en un Data Warehouse (DW).

Forman parte de un modelo dimensional (Kimball):

- **Fact tables** → eventos o mediciones (transacciones, ventas, clics ya procesados)

- **Dimension tables** → catálogo de entidades (cliente, producto, fecha, tienda)

## Características

- Tienen métricas numéricas (importe, cantidad, distancia, duración, etc.)

- Tienen foreign keys a dimensiones

- Son aditivas (o semi/non-aditivas)

- Son **curadas** y **consistentes**

## Ejemplos

FactVentas:

| fecha_key | cliente_key | producto_key | cantidad | total_venta |

FactEventosWeb:

| fecha_key | user_key | page_key | tiempo_en_pantalla_ms |

## Objetivo

- **Hacer analítica rápida, confiable y consistente.**

## 3. Relación entre ambos

Los ***raw logs*** son **input**, mientras que los ***fact data*** son **output** luego de pasar por un pipeline ETL/ELT.

## 4. Resumen corto

| Concepto                               | Raw Logs                        | Fact Data                      |
| -------------------------------------- | ------------------------------- | ------------------------------ |
| ¿Crudos?                               | Sí                              | No                             |
| ¿Limpios y validados?                  | No                              | Sí                             |
| ¿Modelados?                            | No                              | Sí                             |
| ¿Sirven para analítica directa?        | No                              | Sí                             |
| ¿Sirven para trazabilidad / auditoría? | Sí                              | Rara vez                       |
| ¿Dónde viven?                          | **Data Lake – Capa RAW**        | **Data Warehouse – Marts**     |
| ¿Formato común?                        | JSON, CSV, Parquet sin procesar | Parquet/Delta con esquema fijo |

**Los raw logs son los datos crudos tal como llegan de la fuente, mientras que el fact data es esa información ya procesada y preparada para análisis en un data warehouse**
