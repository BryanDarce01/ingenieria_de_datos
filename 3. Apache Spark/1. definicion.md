# Apache Spark 
Es un **motor de procesamiento de datos distribuido**, pensado para trabajar con muchísimos datos de forma rápida y paralela.

En otras palabras:

***Spark sirve para procesar y analizar grandes volúmenes de datos que no caben en una sola máquina.***

# ¿Qué es?

Es **framework open source** que corre sobre **clusters** (varias máquinas) y permite hacer:

- Transformaciones de datos

- Agregaciones (group by, join, etc.)

- Procesamiento batch y streaming

- Machine Learning

- Análisis SQL

Todo esto mucho más rápido que herramientas tradicionales como **MapReduce**.

## ¿Por qué es tan rápido?

Porque:

- Trabaja en **memoria (RAM)** en lugar de escribir a disco todo el tiempo

- Divide el trabajo en **tareas paralelas**

- ptimiza automáticamente los planes de ejecución
