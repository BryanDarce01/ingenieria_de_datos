# 1. Executors

Un executor es un [**proceso JVM**](jvm.md) que corre en un worker node.

## Características técnicas

- Se lanza al inicio de la aplicación

- Vive durante toda la aplicación (no por job)

- Tiene:

    - Memoria asignada (``executor-memory``)

    - Cores (``executor-cores``)

# Qué hacen los executors

## 1.1 Ejecución de tasks

Reciben tasks serializadas desde el driver

Ejecutan operadores físicos

Procesan una partición por task

## 1.2 Gestión de memoria

- Almacenan:

    - Cache (``persist``)

    - Shuffle data

- Usan el modelo de memoria de Tungsten:

    - Execution memory

    - Storage memory

## 1.3 Shuffle

- Escriben shuffle files en disco local

- Sirven bloques shuffle a otros executors
