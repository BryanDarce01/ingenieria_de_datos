# ¿Qué es Catalyst?

Catalyst es el optimizador lógico y físico.

Su trabajo es:

- Analizar tu consulta

- Optimizar el plan lógico

- Elegir estrategias físicas

- Generar el plan final

Pero Catalyst no ejecuta datos directamente.

Produce el plan que luego [Tungsten](12.%20tungsten.md) ejecuta eficientemente.

# ¿Qué son los RDDs?

RDD es la estructura base de ejecución distribuida.

RDD:

- Representa datos particionados

- Maneja el lineage

- Maneja distribución entre nodos

- Ejecuta tareas en los [executors](3.%20executors.md)

RDD es el nivel más bajo del modelo.

En otras palabras:
- RDD es la unidad básica de ejecución distribuida.

Sin embargo:

- No es el nivel donde ocurre la optimización moderna.

- Es el nivel donde se ejecutan tasks en los [executors](3.%20executors.md).

# La diferencia

``` scss

El código (SQL / DataFrame)
        ↓
Catalyst (optimiza el plan)
        ↓
Tungsten (optimiza ejecución física)
        ↓
RDD (ejecución distribuida real)

```

# Comparacion

| Componente | Qué hace                                        |
| ---------- | ----------------------------------------------- |
| RDD        | Ejecuta datos distribuidos y maneja particiones |
| Catalyst   | Optimiza el plan lógico y físico                |
| Tungsten   | Optimiza memoria y CPU durante la ejecución     |


# Diferencia

Diferencia clave conceptual

RDD:

- Es modelo de datos distribuido.

- Bajo nivel.

- No tiene optimización automática avanzada.

Catalyst:

- Es el cerebro que optimiza consultas declarativas.

- Solo aplica a DataFrames/Datasets/SQL.

Tungsten:

- Es el motor que hace que la ejecución física sea rápida.

# Por qué DataFrames son más rápidos que RDD

Porque DataFrames usan:

- Catalyst → optimización automática

- Tungsten → ejecución binaria optimizada

RDD no pasa por Catalyst.

RDD no usa todas las optimizaciones de Tungsten.

Por eso hoy en día se recomienda:

- Usar DataFrames casi siempre.

# Resumen

RDD = motor distribuido base

- ***“La ejecución física de un DataFrame termina generando RDDs de InternalRow que se ejecutan distribuidamente.”***

Catalyst = optimizador de consultas

Tungsten = motor de ejecución optimizada en memoria y CPU

# ¿Un Dataframe es un RDD?

Resumen claro

✔️ Sí, un DataFrame usa RDD internamente.

✔️ El plan físico se ejecuta como RDDs.

❗ Pero DataFrames agregan Catalyst y Tungsten encima.

RDD es el nivel más bajo.

DataFrame = RDD + Optimización + Motor binario + SQL engine.

Por eso hoy en día:

- RDD se usa en casos muy específicos.

- DataFrame es la API recomendada.
