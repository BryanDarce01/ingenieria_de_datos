# 1. DataFrame

## ¿Qué es?

Un **DataFrame** en Spark es una colección distribuida de datos organizada en columnas con esquema (schema).

Internamente es:

```

Dataset[Row]

```

- Es decir, es un Dataset no tipado cuyos registros son objetos `Row`.

## Características técnicas

- Distribuido en múltiples nodos

- Tiene schema explícito

- Basado en el motor Catalyst Optimizer

- Se ejecuta sobre el Tungsten Engine

- Evaluación lazy

- Puede construirse desde:

    - Parquet

    - Avro

    - JSON

    - CSV

    - JDBC

    - Tablas Hive

    - [RDDs](2.%20elementos_clave/9.%20rdd.md)

## ¿Para qué sirve?

- Procesamiento de datos estructurados y semi-estructurados

- ETL distribuido

- Transformaciones declarativas

- Consultas tipo SQL

- Integración con BI

Es la API más usada en:

- PySpark

- Spark en producción

- Pipelines de datos

## Ejemplo (PySpark)

``` python

    df = spark.read.parquet("s3://bucket/data")
    df.filter("age > 18").groupBy("country").count()
```

# 2. Dataset

## ¿Qué es?

Un **Dataset** es una colección distribuida **fuertemente tipada**.

Solo existe en:

- Scala

- Java

No existe en PySpark (porque Python no es fuertemente tipado en tiempo de compilación).

## Diferencia con el Dataframe

| Característica      | DataFrame           | Dataset                   |
| ------------------- | ------------------- | ------------------------- |
| Tipado              | No tipado (`Row`)   | Tipado (`case class`)     |
| Compile-time safety | ❌                   | ✅                         |
| Lenguaje            | Scala, Java, Python | Scala, Java               |
| Performance         | Muy alta            | Igual o ligeramente mejor |
