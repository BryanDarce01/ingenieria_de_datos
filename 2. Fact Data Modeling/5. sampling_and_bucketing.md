# 1. Sampling (muestreo)

***Es reducir datos para analizar más rápido***

## Qué es

Trabajar solo con una muestra representativa del total de datos.

## Para qué se usa

- Exploración de datos (EDA)

- Pruebas de queries

- Validaciones rápidas

- Análisis estadístico aproximado

## Qué NO hace

- No optimiza joins

- No mejora el diseño del modelo

- No sirve para resultados “oficiales” o financieros


## Ejemplo

``` sql

-- BigQuery
SELECT *
FROM fact_sales
TABLESAMPLE SYSTEM (10 PERCENT);

```

**Idea clave:** Se sacrifica precisión para ganar velocidad.

# 2. Bucketing (clustering / hashing)

***Organizar datos para escalar mejor***

## Qué es

Distribuir los datos en “**cubetas**” (**buckets**) usando un hash de una columna (ej. `user_id`, `order_id`).

## Para qué se usa

- Optimizar **joins grandes**

- Reducir shuffles

- Mejorar queries repetitivas por la misma clave

- Escalabilidad en sistemas distribuidos

## Comparativa

| Aspecto           | Sampling        | Bucketing    |
| ----------------- | --------------- | ------------ |
| Reduce volumen    | ✅ Sí            | ❌ No         |
| Precisión         | ❌ Aproximada    | ✅ Exacta     |
| Optimiza joins    | ❌ No            | ✅ Sí         |
| Uso típico        | Análisis rápido | Producción   |
| Impacto en modelo | ❌ Ninguno       | ✅ Importante |


## ¿Cuál usar en la práctica?

Depende del momento:

- Exploración / pruebas

    ✅ Sampling

- Pipelines productivos / fact tables grandes

    ✅ Bucketing (clustering) + particiones

Nunca:

- ❌ Usar sampling para reportes oficiales
- ❌ Pensar que sampling “optimiza” el modelo

## Resumen

**Sampling reduce datos para explorar; bucketing organiza datos para escalar.**
