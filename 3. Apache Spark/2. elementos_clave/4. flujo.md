# Relación Plan → Driver → Executors

Flujo real:

1. Driver recibe código

2. Driver construye **Logical Plan**

3. Catalyst genera **Optimized Logical Plan**

4. Spark genera **Physical Plan**

5. DAG Scheduler crea **stages**

6. Task Scheduler crea **tasks** (tareas)

7. Executors ejecutan **tasks** (tareas)

8. Driver coordina y recopila resultados

# Resumen técnico

- **Plan**: representación lógica y física del cómputo

- **Driver**:

    - genera planes

    - construye DAG

    - agenda tasks

    - coordina ejecución

- **Executors**:

    - ejecutan operadores físicos

    - manejan memoria

    - hacen shuffle

    - procesan particiones
