# Tungstens

**Tungsten** es el motor de ejecución física optimizada de Spark.

Mientras [Catalyst](11.%20catalyst_optimizer.md) decide qué plan ejecutar, Tungsten optimiza cómo se ejecuta en memoria y CPU.

Fue introducido para:

- Mejorar uso de memoria

- Reducir garbage collection

- Generar código más eficiente

- Optimizar procesamiento en CPU

# Qué hace Tungsten técnicamente

## 1. Gestión manual de memoria

En lugar de usar objetos Java pesados, usa:

- Formatos binarios compactos

- Memoria off-heap (fuera del heap de la JVM)

Eso reduce:

- Overhead de objetos

- Garbage collection

- Uso innecesario de memoria

## 2. Formato binario optimizado

En [RDDs](9.%20rdd.md) tradicionales, cada fila es un objeto Java.

En Tungsten:

- Las filas se almacenan como estructuras binarias compactas

- Mucho más eficiente en CPU cache

## 3. Whole-Stage Code Generation

[Catalyst](11.%20catalyst_optimizer.md) genera código Java dinámicamente que:

- Combina múltiples operadores en un solo bloque

- Evita overhead de llamadas

- Reduce iteradores intermedios

Esto lo ejecuta Tungsten.
