# Materializar un DataFrame

En Spark, un DataFrame normalmente **no contiene datos en memoria.**

Contiene:

- Un conjunto de transformaciones

- Un plan de cómo obtener los datos

- Un [lineage](8.%20lineage.md)

Ejemplo:

``` python 

    df = spark.read.parquet("/data/ventas")
    df = df.filter("year = 2025")

```

En este punto:

- No se ha leído nada.

- No hay datos en memoria.

- Solo existe un plan.

Cuando ocurre una **acción:**

``` python

    df.count()

```

Ahí Spark:

- Ejecuta el DAG

- Lee el parquet

- Aplica el filtro

- Produce resultados reales

Eso es **materializar**.

## Definición técnica:

- Materializar un DataFrame es ejecutar su plan físico y generar los datos reales en memoria o disco.

Cuando hacemos:

``` python

    df.cache()
    df.count()

```

Se materializa y además se guarda el resultado intermedio.
